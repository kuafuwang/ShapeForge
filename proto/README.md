# External evaluator Protobuf artifacts

`tcenv/remote/v1/evaluator.proto` is the only external schema source for the
Phase 2C1 contract. The checked-in Python messages, Python gRPC stubs, and
descriptor set are generated artifacts; the service/runtime is a later phase.

Regenerate from the repository root:

```bash
uv run --group codegen python scripts/generate_evaluator_proto.py
```

CI or a local drift check runs:

```bash
uv run --group codegen python scripts/generate_evaluator_proto.py --check
```

The generator is pinned to **protoc 29.3** and **grpc_python_plugin 1.69.0**.
Set `TCENV_GRPC_PYTHON_PLUGIN` if the plugin is not on `PATH`. The script checks
the protoc version and all generated bytes. The pinned gRPC 1.69 plugin predates
self-reported stub versions, so CI/tool installation must pin that package
version explicitly; a plugin that does emit a different version marker is
rejected. Generation uses only relative proto paths and embeds no host paths or
timestamps.

Python message imports need `protobuf`; importing the stubs additionally needs
`grpcio`. Standard `google.rpc` status/detail messages come from
`googleapis-common-protos`. All three are in the `grpc` project extra and the
development dependency group. None is imported by `tcenv.remote.contracts` or
`LocalEvaluator`.
