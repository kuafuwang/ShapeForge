## 名义费用

按每次软预算 $3 计。都不是绝对账单上限。

| 做法 | 还要新开的搜索 | 名义新增 |
| --- | --- | --- |
| FlashAttention 六次全部新开，不沿用现有目录 | `fa_on` 3 次 + `fa_off` 3 次 | **$18** |
| 计划里的「只缺 4 次所以 $12」 | 要以 `fa_on_1` 和 `fa_on_2` 都已完成、且 `fa_on_3` 与 3 个 off 未跑为前提 | **当前不成立**。`fa_on_2` 没有结果 |
| 只留下已经写完的 `fa_on_1`，其余 FA 用新目录补 | `fa_on` 再 2 次 + `fa_off` 3 次 | **$15** |
| 在上面任何一种 FA 做法之外，另开一次 conv2d off | 再 1 次 | **再 $3** |
| conv2d 的 on 也重做，再加 off | 2 次 | **$6** |

因此名义新增可以是 $15、$18、$21 或 $24，取决于沿用哪几次、conv2d 重不重做。逐项由 owner 写进下面的空栏。脚本现在有 `--max-total-usd`，不写这个参数时它不是整组对照的硬上限。
