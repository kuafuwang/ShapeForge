## 共享 profile 的耦合（本批最容易漏的一点）

`sem_attention_odd_scale` 与 `flash_attention` **共享 `metal-flash-attention` profile**。
第一版 B3 把该 profile 一并删除，结果 `sem_attention_odd_scale`（B4 才迁）立刻无法装配。
处理：profile 与 lowerer 保留，**只有 variant factory 随 `flash_attention` 退役**。
这不是保留死代码：它仍是 `sem_attention_odd_scale` 当前 v1 装配的必需品。

同理，`sem_attention_odd_scale` 成为唯一静态 v1 样本题后，原先以 `flash_attention` 为样本的
`test_backend_phase0.py` 锚点校验改为**确认该任务确已迁移**，不再假装还能做 v1 的 live 校验。

## 内联的 oracle（v2 不许 import harness）

`reference.py` 与 `baselines.py` 不能 import `tasks`/`tcenv`，所以：

- **BitDelta 的解包器**（`[K//32, N] int32 → [K, N] ±1`）内联进 `reference.py`；
- **Mamba-2 的整个 `ssd_chunk_scan` 与三套 ops**（`_MlxOps`/`_TorchOps`/`_RefOps`）内联进
  `reference.py`（fp64）与 `baselines.py`（fp32 / half / compile 五个变体）。
  这是有意重复：oracle 若 import 被它裁判的实现，就不是 oracle。
- `flash_attention` 的有效标度是 `eff_scale`（直接用 `SM_SCALE`）；
  `sem_attention_odd_scale` 的 `sum_with_log2e` 模式属于 B4。

## 等价性证据

12 组合 × 18 记录 = **216 条**，迁移前用 v1 `prepare_case` 冻结，迁移后 v2 合同重放：

| 任务 | 输入逐字节 | 参考逐字节 | 尺度逐字节 |
| --- | --- | --- | --- |
| flash_attention ×4 | 54/54（q/k/v） | 18/18（o） | 18/18 |
| bitdelta_gemm ×4 | 36/36（x/bits） | 18/18（y） | 18/18 |
| mamba2_chunk_scan ×4 | 126/126（7 个输入） | 18/18（y） | 18/18 |

`evidence/compare-report.json`：**全部逐字节一致**，一次通过。

保留的 IEEE 细节：
- `flash_attention` 只给 `q` 注入特值；
- `mamba2` 只给 `states` 注入（`seed + 104729 * 7`）；
- `bitdelta` 的 ieee 基分布是 `random`（映射回 `normal`），打包的 int32 字不注入（v1 只注入浮点张量）。

## 真机切片（GPU）

`tests/backends/metal/test_task_migration_b3_gpu.py`，**3 passed**。三题的归档 naive 候选在真实
v2 `evaluate_task` 上编译、ABI、正确性、计时全过，dispatch 与 v1 的 grid/threads 一致。

切片暴露了两条只有真机才能确认的规则：

1. **`SHUFFLES` 是代码片段，不是数字**。flash_attention 的 `{{SHUFFLES}}` 由 profile 按
   `log2(TPR)` 生成 `simd_shuffle_xor` 归约序列（TPR=4 → `xor 1`、`xor 2` 两条）。
   把它当数字替换会直接编译失败。
2. **`msl-single` 没有派生标量绑定**。bitdelta 的 v1 候选把 `scale` 声明为
   `constant float& scale [[buffer(2)]]`，v2 报 `buffer 'scale' is neither an ABI tensor nor a
   derived scalar`。候选必须改用合同头提供的**编译常量** `SCALE`，输出槽位随之回到 2。
   另外 bitdelta 的算例名是 `random`/`edge_bits`，不是 `normal`，`quick` 的默认 case 表必须换掉。
