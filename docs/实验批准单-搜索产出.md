# 实验批准单：搜索产出

## 这篇讲什么

- **它只是一张还没执行的对照表。** 写这份文件没有启动搜索，没有调用模型，也没有使用图形芯片（GPU）。
- **费用是名义承诺，不是账单上限。** 已经发出的请求仍可能超出每次 $3。
- **它不构成批准。** owner 填好 δ 和执行记录之前，不能花钱，也不能占图形芯片。实施者没有填写 δ，也没有填写是否执行。

清点时间：2026-11-10。只读脚本是 `experiments/search_yield.py`。它递归读取已有的 `result.json`、`transcript.jsonl`，以及每个 session 的自测记录：`agent_work/<场>/.selfcheck/self_checks.jsonl`、旧的 `agent_work/<场>/self_checks.jsonl`、归档 `candidates/<序号>_<场>/self_checks.jsonl`，没有这些文件时才用 agent 事件上的 `self_checks`。同一场只留一份，新目录优先于旧文件，旧文件优先于归档，归档优先于事件。它自己不调用 `taic run`。

## 对照怎么分

对照臂是今天的默认：`init_samples=1`，`task_ledger` 关，`plateau_after=0`，`sweep_tool` 关。

处理臂同时打开四件事：`init_samples=3`，`task_ledger` 开，`plateau_after=2`，`sweep_tool` 开。

建议题目是 `conv2d` 和 `flash_attention` 的 paper 档。每题每臂 3 次，每次软预算 $3。两题、两臂，每臂 6 次，名义合计 **$36**。这不是账单上限，也不是已经获准的支出。

主指标是配对后的确认加速比之差，算法写在下一节。次指标由 `experiments/search_yield.py` 对一次运行根计算：

| 数 | 算法 |
| --- | --- |
| 初稿到最优的抬升 | 每次运行 `best_speedup / 第一份合格 init 加速比 - 1`，再取这些运行的中位数。init 标签匹配 `init`、`init2`、`init3` 以及旧的 `init.sN`。没有合格 init 加速比的运行不进这个中位数 |
| 原样交回种子的场次比例 | 纳入运行里，`outcome=unchanged` 的 agent 场次，除以全部 agent 场次。这是一个汇总比例，不是每次运行比例再取中位数。一次运行没有 agent 事件时，改用它的 trace 行：`status=unchanged` 的行数除以 trace 行数，分子分母都并进同一个汇总。两边都没有的运行不进这个比例 |
| 最优出现之后的花费比例 | 每次运行 `(最终花费 - 最后一条 improved 行的 cost_usd) / 最终花费`，再取这些运行的中位数。最终花费优先用 `result.json` 的 `spent_usd`；旧记录没有这个字段时，才用 trace 最后一行的 `cost_usd`。两者都是累计花费。最好内核之后没有写出 trace 行的付费会话算在 `spent_usd` 里 |
| 计时自测次数 | 每个 agent session 一条次数，再取这些次数的中位数。同一场只留一份记录，优先级与文首相同。一次运行里有一份旧文件，不会改掉其他场的来源 |

偶数个样本时，中位数是中间两数的平均。脚本若另给每次运行的比例中位数或每次运行的自测合计中位数，字段名带 `per_run`，那两个数不是上表的主次指标。

## 配对

一对的键是任务、`paper` 档、重复编号 `1..3`，以及两边记录的同一个搜索种子。`conv2d` 和 `flash_attention` 走 v2，搜索种子固定为 7。某一边没有记下这颗种子，这一对不成立。

计划样本量是 2 题 × 3 个重复 = 6 对，共 12 次运行。每臂 6 次：`conv2d` paper 3 次，加上 `flash_attention` paper 3 次。

一对的差是处理臂的 `confirmed_speedup` 减去对照臂的 `confirmed_speedup`。只有两边的 `confirmed_status` 都是 `ok`，并且两边都有 `confirmation_source_sha256`，这一对才进入汇总。汇总是这些完整配对差的中位数。偶数个时取中间两数的平均。

未确认、失败、缺少 `result.json`、`confirmed_status` 不是 `ok`，都不拿 `best_speedup` 填补。不成对的运行列出来，不进入中位数。完整配对少于 6，或者 δ 仍是空白，结论是 `inconclusive/未获批准`，四个开关保持关闭。

## 判定

δ（允许的最小差异）留空。是否执行留空。

未填、样本不足、或差异没有过 δ，结果只记 `inconclusive/未获批准`，维持当前默认。四个开关的默认值不因这份文件而改变。
