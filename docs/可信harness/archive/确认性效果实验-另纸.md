# 确认性效果实验（另纸，本阶段不实现）

状态：**另纸，本阶段不实现**。plan-02 第一批只交付预测合同、dry-run/mock、宿主送达与探索性报告。
本文记录以后申请真实确认实验时必须满足的门槛，不是一张已存在的授权单，也不要求当前实现
`confirmatory_min_pairs` 或确认性 verdict。

## 1. 开工前提

- 已有 plan-02 的冻结预测、送达/阴性回执、完整配对采集和探索性结果。
- 另有具名授权，明确预算、真实 cell 是否需要 GPU、独立效果复核人与停止规则。
- `confirmatory_min_pairs` 在校准完成前是**不存在**，不是可以凭经验填写的配置项；未达标时只有
  `uncalibrated + inconclusive`，不得 `supports_effect`、`refuted` 或采纳。

## 2. 校准必须回答的两个目标

1. **区间覆盖**：在事前冻结、与目标运行分布相符的 null/unchanged-control 上，同一区间规则在目标
   nominal level 下的实际覆盖率。真实历史 unchanged-control 必须能说明为何代表当前 target/task、
   seed 间变异、搜索与执行条件；不能只贴一个「目标分布」标签。
2. **功效 / MDE**：在候选样本量下，能否可靠区分冻结的 `min_effect`，并给出支持、反驳和不确定的
   决策目标。只报覆盖率、只报 MDE 或只报单个指标都不算完成。

两个目标必须同时满足，不能只完成其中一个。校准记录还须固定重采样单位、区间方法、α、目标效应、原始记录、推导过程和授权人。
`confirmatory_min_pairs` 必须严格大于 `exploratory_min_pairs=3`；若推导给出 3 或更小，表示目标未达，
应改更保守的方法或继续申请数据，不能降低门槛。

## 3. 不能替代真实校准的材料

- 自造合成/iid/不合分布的零效应数据只能做状态机和实现正确性测试，不能证明真实
  between-seed run variability 下的覆盖率，也不能解锁 `confirmatory_min_pairs` 或真实采纳。
- 「目标分布替代」不得成为自造 null 的别名。替代记录只能是确实来自目标运行分布、有依据的真实
  unchanged-control 历史；新采真实 cell 仍需另行具名授权。
- 论文样本量、 bootstrap 区间宽度、 reviewer 信心、search best、单次 confirmed speedup 均不能代替
  当前目标的校准。3 对零宽或极窄区间没有可声称的 nominal 覆盖率。

## 4. 确认实验的状态与验收

只有校准记录有效、区间规则冻结且 `pairs >= confirmatory_min_pairs` 时，才可按定向区间给出：

- 下界达到 `min_effect` 且护栏不越界 → `supports_effect`；
- 上界低于 `min_effect`，或实测护栏越界 → `refuted`；
- 区间跨阈值、样本/证据不足 → `inconclusive`；绑定、送达、配置或账单不可信 → `invalid`。

规划中的反例：`[1,1,1]`、`[1,1,0.9]` 在 3 对时不得支持；`[0.2,0.2,0.2]` 不得反驳；
只有合成 null、缺覆盖率或缺功效/MDE 的校准记录不得确认；补足有效校准与样本后才允许确认正对照。
效果成立仍不自动等于值得采纳，成本、人工分钟和独立 adoption 决定另算。

任何真实校准、真实确认 cell、付费 review 或 GPU 均需另行具名授权；本附件本身不授权任何执行。
